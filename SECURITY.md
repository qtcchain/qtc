# Security Policy

## Supported Versions

See our website for versions of QTC that are currently supported with
security updates: https://qtc.dev/

## Reporting a Vulnerability

To report security issues, email the QTC Development Team at team@qtc.dev
(not for support).

If sensitive material is involved, ask the QTC Development Team for the current
disclosure key before sending secrets. Do not use inherited upstream keys for
QTC vulnerability reports.
